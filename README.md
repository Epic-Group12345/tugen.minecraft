# tugen.minecraft

Мини-приложение Minecraft для TUGEN на React Native: пространство игры внутри окна лаунчера. Пишется
на [tugen.sdk](https://github.com/Epic-Group12345/tugen.sdk) — тем же SDK, что получат сторонние
разработчики, — и служит образцом для них.

С лаунчером общается только через `useHost()` из SDK: файлы своей папки, загрузки, сеть и запуск
процесса.

## Разделы

Разделы игры (Обзор, Сборки, Контент, Скины, Настройки) объявлены в манифесте
(`src/manifest.ts`). Лаунчер помнит открытый раздел и передаёт его в `App` пропом `section`; кнопка
раздела переключает его через `useHost().navigation.open(id)`, и лаунчер присылает новый `section`.
Пустой или незнакомый `section` — открывается первый раздел.

Экраны — в `src/sections/`:

- **Обзор** — основная сборка, журнал запуска и каталог серверов: поиск по каталогу, пагинация,
  онлайн и подключение выбранной сборки к серверу. Без сборки кнопка подключения недоступна.
- **Сборки** — список с состояниями запуска и меню действий: выбор основной сборки, папки игры
  (включая миры, моды, ресурспаки, шейдеры, скриншоты и журналы), переименование, копирование и
  удаление с подтверждением. То же меню есть у основной сборки на обзоре. Копирование и удаление
  недоступны во время запуска; пока сборка копируется, её нельзя запустить или удалить. Форма
  создания позволяет выбрать название, версию игры, загрузчик и его версию.
- **Настройки** — группы параметров игрока, производительности и запуска: ник, память, аргументы JVM
  и размер окна игры. Текст сохраняется по завершении ввода (уход из поля или Enter).
- **Контент и Скины** — пока заглушки «Скоро здесь будет».

Логика — ядро в `src/core/` (`MinecraftCore`); экраны берут его через хуки `src/core/react.tsx`
(`useCore`, `useSettings`, `useBuilds`, `useMainBuildId`, `useLaunchState`), `App` обёрнут в
`CoreProvider`. Адрес сервера проверяется перед тем, как попасть в аргументы запуска; API-ответ
каталога проверяется на границе мини-приложения.

Строки пакета — в `src/i18n.ts` (русский и английский, язык — `useHost().system.locale`).

## Острова и оформление

Плашки лаунчера лежат поверх мини-приложения сверху; их размер приходит в Safe Area SDK. Нижний остров
лаунчера скрыт, его место занимает собственная навигация игры (`src/ui/island.tsx`). Иконки разделов
встроены в пакет и рисуются компонентом `SvgIcon` из SDK через нативный SVG-растеризатор. Нижний остров
измеряет `onLayout` и задаёт нижний отступ для прокрутки экранов.

Классы Uniwind из этой папки лаунчер не собирает, поэтому оформление — `StyleSheet.create`
(цвета — `src/ui/theme.ts`), тени — `boxShadow` строкой. «Статичное стекло»: размер кнопок не
меняется, ни масштаба, ни блюра — наведение и нажатие проявляют слои с тенями через opacity
нативным драйвером (`src/ui/animation.ts`).

## Манифест

- `icon: 'Cube'` — иконка Gravity UI (PascalCase) для карточки и верхней плашки лаунчера.
- `presentation: 'embedded'` — мини-приложение рисуется внутри окна лаунчера на всё окно.

Нативной части у мини-приложения нет: за `GameHost` стоят модули лаунчера и ядро
[tugen.core](https://github.com/Epic-Group12345/tugen.core).

## Переезд из лаунчера

Обзор, сборки и настройки уже здесь; остальное из
[tugen.launcher](https://github.com/Epic-Group12345/tugen.launcher) (`src/games/minecraft` — уже на
том же API SDK) переезжает сюда:

| Что                                               | Сейчас в лаунчере                                                    |
| ------------------------------------------------- | -------------------------------------------------------------------- |
| сборки: список, создание, настройки               | `services/game/builds.ts`, `settings.ts`, `setup.ts`                 |
| версии Mojang, описание версии, загрузчики, Java  | `services/game/mojang.ts`, `version.ts`, `loaders.ts`, `java.ts`     |
| подготовка и запуск, журнал                       | `services/game/launch.ts`, `runtime.ts`, `logs.ts`                   |
| моды и контент сборки, импорт из других лаунчеров | `services/game/content.ts`, `imports.ts`                             |
| офлайн-игрок, раскладка папки                     | `services/game/offline.ts`, `paths.ts`                               |
| экраны                                            | `pages/builds`, `components/build-*`, `game-controls`, `import-list` |

Вызовы `native/game` при переезде заменяются на `useHost()`. Это только JS, поэтому до игроков всё
доходит по воздуху, без нового релиза.
